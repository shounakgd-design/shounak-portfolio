#  Shounak Portfolio

A modern **full-stack personal portfolio website** built to showcase my skills, projects, experience, and development journey.

## 🛠️ Tech Stack

**Frontend**

* React.js
* Vite
* JavaScript
* CSS

**Backend**

* Node.js
* Express.js
* MongoDB
* Mongoose
* REST APIs

## ✨ Features

* Responsive portfolio website
* Projects showcase
* Skills & experience
* Blog section
* Contact section
* User authentication
* Dynamic data using REST APIs
* MongoDB database integration

## 📁 Project Structure

```text
shounak-portfolio/
├── frontend-src/
├── backend-src/
├── package.json
├── run-dev.js
└── README.md
```

## ⚙️ Run Locally

```bash
git clone https://github.com/shounakgd-design/shounak-portfolio.git
cd shounak-portfolio
npm install
```

Start the frontend:

```bash
cd frontend-src
npm run dev
```

Start the backend:

```bash
cd backend-src
npm run dev
```
